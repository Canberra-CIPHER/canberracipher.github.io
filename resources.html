A collection of resources that students may find useful.

OnShape

Tutorials for OnShape, the Computer Aided Design (CAD) program used by our team. These can be accessed for free, all they require is an OnShape account. Although OnShape can be used for all kinds of design work, it is used by FRC teams globally, and this website provides in-depth guides on how to utilise 3D design for robotics in particular. From basic tools to complex mechanisms, this website is your first introduction into all things CAD.

FIRST

FIRST Australia is the program we participate in, and this website includes Australian specific details for all FIRST programs such as dates, locations, and statistics. This website will answer all your questions about not only FRC but the broader FIRST organisation and how it operates in Australia.

GitHub

Github is a platform that allows people to access and share code across different locations and systems, from national collaboration to internal team organisation. This is a link to our official GitHub repository, which is home to the code used to power our robots. With this, our programmers are able to work efficiently together and take inspiration from the dozens of other repositories owned by FRC teams across the globe.

2025 Build Blog

Chief Delphi, a website for communication about all FIRST-related issues, allowing for public discussion on community relevant topics. This is a link to a blog documenting Canberra CIPHER’s 2025 build season, as chronicled by our head mentor. It is a look into how a build season typically operates and the kinds of thought processes and experimentation that happens.

WPI Lib

A software library used by many teams.
